My Website

A basic, responsive web page built using pure HTML & CSS only (no JavaScript).

📄 Overview

This project is a simple static web page template featuring a header with navigation and login/logout links, a hero banner, a middle content section with feature cards, an "About" block, and a footer.

🗂 File Structure
├── index.html      # Main web page (HTML + embedded CSS)
└── README.md        # Project documentation
✨ Features
Header: Logo on the left, navigation links (Home, About, Services, Contact) in the center, and Login/Logout buttons on the right
Hero Section: Welcome banner with heading, description, and call-to-action button
Main Content: Feature cards section + About section
Footer: Copyright text and quick navigation links
Responsive Design: Adapts to mobile and tablet screens using CSS media queries
No JavaScript: Built with only HTML5 and CSS3
🎨 Customization

You can easily customize:

Colors: Edit the CSS variables/colors in the <style> section (currently uses 
#2c3e50, 
#1abc9c, #fff)
Content: Replace placeholder text in the hero, cards, and about sections
Logo: Replace the text logo with an image by editing the .logo div
Links: Update href values in the navigation and footer to point to real pages/sections
🚀 How to Use
Download or clone this file
Open index.html in any web browser
Edit the HTML/CSS directly in a code editor (e.g., VS Code) to customize
🛠 Built With
HTML5
CSS3 (Flexbox, Media Queries)
📌 Notes
This is a static front-end template — no backend or database is connected
Login/Logout links are placeholders and are not functional without backend integration
